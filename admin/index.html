RESUMEN DE ACCESO

¿Qué es el tiempo de acceso?

Es el plazo durante el que tu cuenta puede utilizar el panel de Focus Guard. Cuando llega la fecha indicada, tu sesión se cierra y pierdes el acceso al panel hasta que el owner amplíe o retire el límite.

Gestión por aulas y grupos

Crea políticas específicas para cada aula. Asigna el mismo nombre de aula/grupo en el registro de cada dispositivo.

Máximo 50 dominios por grupo. El nombre debe coincidir con el campo «Aula / grupo» del dispositivo. Si no existe una política para ese grupo, se aplicará la política global.
