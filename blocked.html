Esta web está bloqueada

Focus Guard ha aplicado las restricciones de navegación configuradas por tu centro educativo.

¿Por qué puede haberse bloqueado?

  • Lista negra global: el dominio está marcado para bloquearse siempre, incluso cuando el modo de navegación es libre.
  • Bloqueo total: el centro o el administrador ha activado el bloqueo de todas las páginas web.
  • Lista permitida: el dominio no está incluido entre las páginas autorizadas.
  • Normas del aula o grupo: se está aplicando una política específica para tu clase.
  • Problema de conexión o sincronización: no se ha podido comprobar la política con Firebase y puede haberse activado el bloqueo de seguridad.

Estos son los motivos posibles; esta pantalla no siempre puede identificar cuál ha provocado el bloqueo concreto. Si crees que se trata de un error o necesitas la página para una actividad, contacta con tu profesor o con el administrador.
