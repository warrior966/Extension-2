# Lista de comprobación manual

- [ ] La extensión se carga desde `chrome://extensions` sin errores.
- [ ] Añadir `example.com` lo muestra en la lista.
- [ ] Añadir el mismo dominio por segunda vez muestra un aviso.
- [ ] Un dominio inválido se rechaza.
- [ ] Quitar un dominio lo elimina de la lista.
- [ ] Con el bloqueo desactivado, los dominios configurados siguen accesibles.
- [ ] Con el bloqueo activado, la navegación principal a los dominios configurados se bloquea.
- [ ] Desactivar el bloqueo vuelve a permitir la navegación.
- [ ] Al cerrar y abrir el popup, la configuración persiste.
- [ ] La extensión no realiza solicitudes de red propias ni transmite la lista.
